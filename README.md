## Idea de proyecto
Descripción del proyecto
Mi idea es hacer un bot de discord, que tenga multiples funciones aprendidas en el curso, que tenga como objetivo promover la conciencia ambiental y ayudar a implementar habitos mas sostenibles.

El bot permitirá calcular el consumo eléctrico aproximado de algunos aparatos, registrar acciones ecológicas en un diario personal, compartir memes relacionados con el medio ambiente, descubrir datos curiosos y participar en desafíos y minijuegos sobre sostenibilidad.

Modelos del curso que combinaria: 
1. Bot de Discord: será la herramienta principal con la que los usuarios interactuarán mediante comandos.
2. Diario virtual con base de datos: permitirá registrar acciones ecológicas y consultar el historial personal.
3. Sitio web de memes / contenido de memes: el bot podrá compartir memes ambientales o los usuarios podrian crearlos.
4. Eco-calculadora: permitirá estimar el consumo de energía eléctrica de distintos aparatos y ofrecer recomendaciones para ahorrar.
Además, se incluirán funciones complementarias de trivia, datos curiosos, desafíos y minijuegos.


### Funciones principales
**1. Consejos ambientales**
El bot compartirá consejos para reducir residuos, ahorrar agua y electricidad, reciclar y consumir de manera responsable.

Ejemplo de comando: !consejo
**2. Eco-calculadora de energía**
El usuario podrá ingresar la potencia de un aparato en watts y las horas de uso para calcular su consumo eléctrico aproximado en kilovatios-hora (kWh). También recibirá sugerencias para reducir el consumo.

**3. Diario ecológico**
Utilizariamos la estructura del diario personal, no esta definida que funcion exacta tendra, pero un ejemplo seria que cada usuario podría registrar acciones positivas para el medio ambiente, y combinarlo tal vez con un sistema de puntaje en la comunidad. Los registros se guardarán en una base de datos para poder consultar el historial.

**4. Memes ambientales**
El bot compartirá memes relacionados con el reciclaje, el cambio climático, la contaminación y otros temas ambientales. El contenido buscará informar y generar interés mediante el humor.

**5. Datos curiosos**
El usuario podrá pedir un dato aleatorio sobre animales, plantas, océanos, energía renovable, contaminación o cambio climático.

**6. Desafíos ecológicos**
El bot propondrá retos individuales o grupales, diarios o semanales. Algunos ejemplos son evitar productos descartables durante un día, separar los residuos o reducir el tiempo de ducha.

**7. Minijuegos y trivia**
Los usuarios podrán responder preguntas sobre el medio ambiente, jugar a verdadero o falso o participar en pequeños cuestionarios. Las respuestas correctas podrán sumar puntos.

**8. Puntos y clasificación**
El bot podrá otorgar puntos por participar en juegos y completar desafíos. Los usuarios podrán consultar sus puntos y, si se implementa, ver una clasificación de la comunidad.

**9. Progreso personal**
A partir de los registros del diario y los puntos obtenidos, el bot podrá mostrar un resumen de las acciones registradas y de los desafíos completados.
Los puntos y los registros representan acciones declaradas por los usuarios; no prueban por sí solos una reducción real de emisiones o de contaminación.
